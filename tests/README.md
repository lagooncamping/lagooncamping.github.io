# ชุดทดสอบอัตโนมัติ

ลองใช้หน้าจองแบบอัตโนมัติ 26 ข้อ (จองบ้านครบทุกหลัง จองเต็นท์ กรอกฟอร์มผิด แผนผัง และเช็กว่าราคาในหน้าเว็บ ระบบ Google และหน้าแอดมินตรงกัน)

รัน: `node tests/booking.test.js` (ต้องมี Node.js และ Playwright)

- ไม่แตะเว็บจริง และไม่ส่งการจองเข้า Google Sheet
- เปิดหน้าจองชั่วคราวเฉพาะตอนทดสอบ (ไฟล์ booking.html ไม่ถูกแก้)
- ควรรันทุกครั้งก่อน push และหลังแก้ราคาหรือเพิ่ม/ลบบ้าน

## หน้าหลังบ้าน

รัน: `node tests/admin.test.js` — ลองเข้าหลังบ้านด้วย PIN เพิ่มการจอง แก้ไขการจอง (ย้ายวัน เพิ่ม/ลดบ้าน แก้ยอด) แก้ช่วงปิดบ้าน กันจองซ้อน และเหมาลาน 14 ข้อ

- รัน `google-apps-script/Code.gs` ในเครื่องกับชีตจำลอง ไม่แตะชีตจริงและเว็บจริง
- ควรรันทุกครั้งหลังแก้ `js/admin.js` หรือ `Code.gs`

## ภาษาอังกฤษ + โหมดมืด

รัน: `node tests/i18n.test.js` — เปิดทุกหน้าเป็นภาษาอังกฤษแล้วเช็กว่าไม่เหลือภาษาไทย, ราคา/เวลา/เบอร์ในคำแปลตรงกับภาษาไทย, จองในโหมดอังกฤษได้จนถึงหน้าชำระเงิน, กดกลับเป็นไทยได้, โหมดมืดจำค่าได้ 17 ข้อ

- ควรรันทุกครั้งหลังแก้ข้อความบนเว็บ (ถ้าขึ้นว่า "ยังเป็นภาษาไทย" ให้เพิ่มคำแปลใน `js/i18n-en.js`)
