# เว็บ The Lagoon Camping Resort

## ดูเว็บ
ดับเบิลคลิกไฟล์ `index.html` เว็บจะเปิดขึ้นมาใน Chrome

## เปิดโปรเจกต์นี้ใน Claude Code
**วิธีที่ 1: ใช้แอป Claude บนคอม (ง่ายที่สุด)**
1. เปิดแอป Claude แล้วกดแท็บ **Code**
2. เลือกโฟลเดอร์ `lagoon-website` นี้
3. พิมพ์สิ่งที่อยากให้แก้เป็นภาษาไทยได้เลย

**วิธีที่ 2: ใช้ใน Terminal**
1. เปิด PowerShell แล้วติดตั้ง (ทำครั้งเดียว): `irm https://claude.ai/install.ps1 | iex`
2. เข้าไปที่โฟลเดอร์นี้: `cd Documents\lagoon-website`
3. พิมพ์ `claude` แล้วกด Enter

Claude Code จะอ่านไฟล์ `CLAUDE.md` เองทุกครั้ง ในไฟล์นั้นบอกไว้แล้วว่าเว็บนี้คืออะไรและควรตอบเป็นภาษาไทย

## ตัวอย่างคำสั่งให้ลองพิมพ์
- `อธิบายให้ฟังหน่อยว่าแต่ละไฟล์ในโปรเจกต์นี้ทำอะไร`
- `เปลี่ยนราคาบ้านหลังเล็กเป็น 1,400 บาท`
- `เพิ่มรูปใหม่ img/bbq.jpg ลงในแกลเลอรี คำบรรยายว่า "ปิ้งย่างริมน้ำ"`
- `เปลี่ยนสีหลักของเว็บเป็นสีเขียวป่า`
- `เพิ่มปุ่ม LINE ลอยอยู่มุมขวาล่าง`
- `ทำให้เมนูบนมือถือกดเปิด-ปิดได้`
- `ช่วยเอาเว็บนี้ขึ้นออนไลน์ฟรีด้วย GitHub Pages ทีละขั้นตอน`
